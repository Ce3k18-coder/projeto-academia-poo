# Sistema de Academia

Este projeto representa de forma simples um sistema de academia utilizando conceitos de Programação Orientada a Objetos em Java.

O sistema possui diferentes tipos de alunos, controle de plano, registro de check-in e organização dos alunos em turmas. Durante o desenvolvimento foram aplicados os conceitos de abstração, encapsulamento, herança e polimorfismo.

Também foram utilizados relacionamentos entre as classes, como associação entre Aluno e Plano, composição entre Aluno e CheckIn e agregação entre Turma e Aluno.

O projeto foi inicialmente modelado através de um diagrama de classes UML e posteriormente transformado em código Java.
