# Diagramas UML — Academia CorpoAtivo

## Sobre a atividade

Esta atividade apresenta a modelagem UML do sistema Academia CorpoAtivo, desenvolvido em Java, com base na classe principal `AppAcademiaCorpoAtivo.java` e nas demais classes disponibilizadas pelo professor.

Foram elaborados quatro diagramas UML: Casos de Uso, Sequência, Estados e Atividades.

## 1. Diagrama de Casos de Uso

O diagrama de casos de uso apresenta as principais funcionalidades disponíveis no sistema Academia CorpoAtivo.  
Ele representa as interações conceituais entre um operador e as operações relacionadas aos alunos, planos e registros de frequência.  
Seu objetivo é demonstrar o que o sistema permite realizar, sem detalhar a implementação interna.  
O operador é uma representação da utilização do sistema, pois o código disponibilizado executa suas demonstrações pelo método `main`.

## 2. Diagrama de Sequência

O diagrama de sequência demonstra a ordem das interações entre os objetos durante a execução de uma funcionalidade.  
Ele apresenta a comunicação entre as classes envolvidas, destacando as chamadas de métodos e suas respostas.  
A representação permite compreender como os objetos colaboram para executar as operações do sistema.  
Também facilita a identificação das responsabilidades de cada classe durante o processo.

## 3. Diagrama de Estados

O diagrama de estados representa as mudanças de estado de um plano ao longo de seu ciclo de funcionamento.  
Ele demonstra as transições que ocorrem quando o sistema executa operações relacionadas ao avanço das etapas do plano.  
As condições de transição ajudam a identificar quando uma mudança é permitida ou impedida.  
Seu objetivo é apresentar o comportamento do objeto diante dos eventos definidos no sistema.

## 4. Diagrama de Atividades

O diagrama de atividades representa o fluxo de execução de um processo da Academia CorpoAtivo.  
Ele apresenta as ações realizadas pelo sistema, incluindo decisões e caminhos alternativos quando aplicáveis.  
O diagrama permite visualizar a sequência das operações desde o início até a conclusão do processo.  
Sua finalidade é facilitar a compreensão das regras e do funcionamento da atividade representada.

## Considerações finais

Os diagramas UML auxiliam na compreensão da estrutura comportamental do sistema Academia CorpoAtivo, representando suas funcionalidades, interações, estados e fluxos de execução.

A atividade foi desenvolvida com base no projeto Java disponibilizado pelo professor.
